## Grouping rules (applied dynamically to any column, incl. future ones)

The form groups columns by **keyword patterns on the header text** (not by fixed
position), so a newly added column lands in the right section automatically:

- **Media** — header contains EXTERIOR / INTERIOR / VIDEO / INSTAGRAM / YOUTUBE / PHOTO_URLS / VIDEO_URLS / *_URL / MEDIA_FOLDER / PHOTO COUNT / VIDEO COUNT → read-only.
- **Status** — STATUS / LAST_UPDATED → read-only.
- **Pricing** — RATE / PRICE / NEGOTIABLE / EMI / DOWN PAYMENT.
- **Documents** — INSURANCE / INS / RTO / RC STATUS / HYPOTHECATION / LOAN / NOC / FINANCE / WARRANTY / ZERO DEP.
- **Vehicle Details** — KM / MILEAGE / ACCIDENT / FLOOD / REPAINT / CONDITION / SERVICE / REASON FOR SALE / BEST FEATURES / KNOWN ISSUES / OWNERSHIP.
- **Vehicle Information** — COMPANY / MAKE / MODEL / MANUFACTUR / VARIANT / FUEL / TRANSMISSION / COLOUR / CAR NUMB / LAST 4 / LOCATION / STOCK / SR NO / YEAR.
- **Other Information** — anything that matches none of the above (still shown, never hidden).

## Read-only policy (why)

`CAR NUMB` is the identity key. Media + system columns are read-only **in this
form** because the Phase-8 rules forbid modifying the media/Supabase workflow —
those columns are owned by the Media panel (photos/videos/links) and the sold
workflow. They are still fully **visible** (View Details shows every field).
