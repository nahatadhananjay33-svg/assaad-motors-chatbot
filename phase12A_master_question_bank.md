# Phase 12A — Master Question Bank (STEP 3)

*Research only.* Everything a real used-car buyer may ask, grouped by category,
with representative phrasings (English + Hinglish/Hindi/Marathi flavour). Each
category is tagged with how it should be answerable:

- **[DATA]** answerable from an inventory field (per car)
- **[SPEC]** needs a new spec/feature field
- **[FAQ]** dealership policy answer (not per car)
- **[CALC]** derivable from existing data
- **[TEAM]** pivot to visit / human when not on file

---

## A. Availability & Identity  [DATA]
- Is this car available? / abhi hai kya? / still in stock?
- Which cars do you have? full list / catalogue
- Do you have a Creta / Swift / Fortuner?
- What year? / kitne saal purani? / model year
- Registration number / RTO / MH01?
- How many of this model do you have?

## B. Pricing & Value  [DATA/FAQ]
- Price? / kitne ki hai? / on-road price? / ex-showroom?
- Is the price negotiable? last price? best price? [FAQ: fixed]
- Why is it priced like this? / market se compare
- What's included in the price — RC transfer, insurance? [FAQ]
- Price range if not fixed / starting from

## C. Budget & Discovery  [DATA]
- Cars under 5/8/10 lakh / X budget ke andar
- Cheapest car / sasti gaadi / value for money
- Best car in my budget for family / first car / city use

## D. Engine & Performance  [SPEC]
- Engine cc? / kitna cc? / power (bhp)? torque?
- Petrol/diesel/CNG/hybrid/electric? [DATA fuel]
- Mileage / average / kmpl (city & highway)?
- Turbo? naturally aspirated?
- Pickup / performance / highway comfort

## E. Transmission & Drive  [DATA/SPEC]
- Manual or automatic? AMT/CVT/DCT/iMT? [DATA + SPEC subtype]

- 2WD / 4WD / AWD? drivetrain

## F. Fuel & Running Cost  [DATA/CALC]
- Fuel type [DATA] / CNG kit fitted? company or after-market?
- Real mileage / running cost per km [CALC]

## G. Mileage / Odometer  [DATA]

## Coverage summary

| Answer type | Categories | Current status |
|---|---|---|
| **[DATA]** per-car | A,B,C,G,H,I,J,K,R,T,U,V,AD | Engine works; **condition/docs/service/insurance data mostly empty** |
| **[SPEC]** new fields | D,E,F,L,M,N,O,P,Q,W | **Not modelled** — biggest gap |
| **[FAQ]** policy | B,R,S,T,U,X,Y,Z,AB,AC,AE | Well covered (19 FAQ intents) |
| **[CALC]** derived | F,V,X | Partly (down-payment estimate exists) |

**Headline:** the largest unmet demand is **[SPEC] features/specs** (Sections D–Q, W)
— these have no fields today and represent a very large share of real buyer questions.
